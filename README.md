# FYP Website

Professional landing page for the **AI-Based Laryngeal Cancer Screening** Final Year Project app.

## Open locally

Double-click `index.html`, or from this folder run:

```bash
# PowerShell
start index.html
```

Or serve with any static server:

```bash
npx serve .
```

## Branding

Uses the same assets and color theme as the FYP mobile app:

- Logo: `assets/app-logo.png`
- Hero illustration: `assets/pain.png`
- Colors: `#fff7fa` background, `#8c1417` accent/heading
